# 7. Para onde seguir

Este livro para no que o Pygame-APC já coloca na mão de quem está em APC: objeto, sequência, dicionário, função e texto. O Python Fluente continua depois disso, em classes, iteradores, concorrência e metaprogramação. O projeto não precisa reescrever esses capítulos. Precisa apontar para eles.

## Mapa de leitura

| No Pygame-APC | No Python Fluente, 2ª edição |
| --- | --- |
| Perfil, exercício e o tipo de cada valor | Cap. 1. O modelo de dados de Python |
| Lista de tópicos, desafios e mensagens | Cap. 2. Uma coleção de sequências |
| Placar e conjunto de desafios resolvidos | Cap. 3. Dicionários e conjuntos |
| Enunciado, saída do programa, chave mascarada | Cap. 4. Texto em Unicode versus bytes |
| Funções dos tutores e do placar | Cap. 7 e 8. Funções como objetos e dicas de tipo |

Os volumes 2 e 3 seguem com classes, protocolos, geradores e programação assíncrona. Quando a API do projeto usar `async def`, o caminho é o capítulo 21, não um resumo feito aqui.

## O que é deste projeto

Os capítulos 1 a 6 são do Pygame-APC, APC, CIC / DCC, UnB. Eles descrevem o ambiente de exercícios, os tutores agentes de aprendizagem e o placar. Não substituem o Python Fluente e não alteram o texto do Ramalho.
