# 1. O Pygame-APC

O Pygame-APC é o ambiente em que você pratica Python na disciplina de APC. Ele junta três coisas que costumam ficar separadas: um exercício com enunciado, um lugar para escrever e rodar código, e um tutor que conversa sobre o que você tentou.

A visão do produto cabe numa frase: uma experiência prática, guiada por exercícios e mediada por tutores de IA. O fliperama e o placar existem para a progressão ficar visível. O estudo mesmo acontece no exercício e na conversa com o tutor.

## O que você encontra ao entrar

- **Exercícios.** Você descreve um tema e uma dificuldade. O sistema devolve um enunciado, exemplos de entrada e saída, e um editor para a sua solução.
- **Tutores agentes de aprendizagem.** Cinco tutores, cada um com um papel. Nenhum deles entrega o programa pronto.
- **Histórico.** A conversa pode ser retomada, renomeada ou arquivada.
- **Placar de aprendizados.** Mostra o XP de estudo e os desafios resolvidos. O ranking de jogos fica em outra lista.
- **Docs API.** A documentação da própria API, com exercícios práticos. A seção dos tutores está marcada como v2.

## Os cinco tutores

| Nome na tela | Papel |
| --- | --- |
| Tutor APC (LOGAN) | Raciocínio de algoritmo, uma pergunta de cada vez |
| Tutor Python (CAIO) | A linguagem, com exemplo genérico, longe do código do exercício |
| Debugador (DEBI) | Lê o erro com você e não entrega a linha corrigida |
| Treinador de Exercícios (TITO) | Organiza entrada, processamento e saída |
| Tutor de Exercícios (MIRA) | Fica no exercício já gerado e não revela a solução de referência |

O modo foco, quando ligado, pede respostas menores: uma etapa por vez. É uma preferência de estudo, não um dado clínico.

## O que este livro faz

Cada capítulo parte de um objeto que já existe no sistema: o perfil do aluno, a lista de desafios, o placar, a função que monta a mensagem do tutor. O código mostrado é curto de propósito. A ideia é você reconhecer a mesma forma quando abrir o Python Fluente.
