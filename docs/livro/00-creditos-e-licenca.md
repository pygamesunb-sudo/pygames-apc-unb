# Python no Pygame-APC

Material de estudo do projeto **Pygame-APC**, da disciplina de Algoritmos e Programação de Computadores (APC), CIC / DCC, Universidade de Brasília.

Este livro é uma obra original do projeto. Os exemplos falam do ambiente que o aluno usa: exercícios, tutores, placar e a Docs API. O texto não reproduz capítulos de outro livro.
